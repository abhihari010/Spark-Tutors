# Spark Tutors

Spark Tutors is a web application for SAT, college application, and essay tutoring. Built with Python and Flask, it provides features such as user registration, appointment scheduling, and contact messaging, all backed by Firebase services.

## Features

- Showcase of tutoring services and plan pricing
- User registration and login with Firebase authentication
- Appointment scheduler preventing conflicting times and weekend bookings
- Contact form storing messages in Firebase Realtime Database
- Account management page for updating user details

## Tech Stack

- Python, Flask
- HTML, CSS, JavaScript
- Firebase Authentication & Realtime Database

## Local Setup

1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the development server:
   ```bash
   python app.py
   ```
4. Open `http://localhost:5000` in your browser.

## Deployment

The site is deployed on Render: https://spark-tutors.onrender.com/ (may take a moment to load on the free tier).

This project was created for a friend's tutoring company as a final CS50 project, providing an opportunity to practice full-stack development.
